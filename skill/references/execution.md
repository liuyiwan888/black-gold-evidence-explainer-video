# 可执行制作流程（ChatCut）

当当前会话提供 ChatCut Desktop 项目与时间线工具时，使用这条路径把分镜实际做成可播放视频。调用工具前读取对应的 ChatCut Skill：视频生成素材读 `chatcut-video-gen`，动效读 `chatcut-create-motion-graphics`，旁白读 `chatcut-voice`，音乐读 `chatcut-music`，字幕或转录读 `chatcut-transcription` / `chatcut-caption-template-impl`。

## 1. 项目与素材

1. 沿用用户指定项目；若没有指定，使用当前明确激活的项目或创建 9:16 项目。记录 `projectId` 和时间线 ID，后续项目调用都带上它们。
2. 检查用户给的文案、照片、视频、录音、音乐与来源链接。用 `inspect_asset` 检查本地媒体；若素材需要进入项目，用 `push_asset`。搜集真实新闻/官方资料前先核实内容与发布日期，给每个证据镜头登记来源。
3. 输出镜头表：镜头号、开始/结束秒、对应文案、素材 ID/出处、字幕、图解、入出动画、配音和音乐轨。用旁白总时长决定镜头时长；不要按片长粗略平均分段。

## 2. 旁白和字幕

- 用户给录音时以录音为主，转录后校正错字并按实际语音对齐字幕。
- 用户只给文案时，先按 `chatcut-voice` 的流程选用用户已确认/可复用的声音；调用 TTS 前检查所选声音、参数与费用，并满足该工具当前要求。若没有已确认声音且工具要求确认，先完成镜头表等独立工作，再取得必要确认。
- 生成或导入字幕后，使用 `read_captions` / `edit_captions` 统一做白色粗体、轻描边、底部安全区。按完整语义断句，一句或两行，不要擅自改写事实。

## 3. 画面和动效

逐个镜头把证据图、实拍、截图、标题和图表放上时间线。图表、时间线、资金/人物关系图使用可编辑矢量或动效素材；优先自行排版真实内容，再以遮罩、高亮、描线、缩放等轻动效依次揭示。来源以小号文字与画面绑定，避免资料卡与字幕争位。

若需生成式视频/图片/音乐，先按对应 ChatCut Skill 获取实际可用模型、素材约束及价格；不得因 Skill 的风格描述而假定生成器免费、已登录或已经获准上传素材。可用静态证据卡、图表或用户素材完成的部分先继续制作。

## 4. 导出与核验

1. 使用时间线预览检查主要段落、动效、字幕和音轨；修复黑帧、缺素材、层级遮挡、错别字及转场过密/过疏。
2. 通过 `export` 导出视频到本地目标路径。导出设置为竖屏 9:16、H.264、AAC；以项目实际支持的分辨率和帧率为准。
3. 通过 `ffprobe` 检查编码、画幅、时长和音轨，并完整解码视频。抽查开头、章间、资料页、数据页与结尾；确保可听见旁白、配乐不盖住人声、来源字幕仍可读。
4. 交付 MP4 文件、来源清单和镜头表。报告实际完成的渲染与核验结果；工具或授权不足时清楚标明停在哪一步，不把制作计划当成成片。

## 可用工具不足时

若会话没有 ChatCut 时间线/导出工具，也没有可用的本地渲染器，此 Skill 只能指导拆解和镜头规划，不能独立产生 MP4。先保留可继续执行的镜头表、素材清单和旁白稿，再说明缺少的渲染依赖。不要声称仅安装 Skill 就会自动获得视频模型、声音、音乐、素材库或渲染环境。
