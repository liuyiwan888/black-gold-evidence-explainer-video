# 黑金证据式解说视频

当用户给主题、文案或资料，并要求做成参考片那种竖屏纪实解说视频时使用。目标是让每段旁白都有对应的视觉证据、图解或情绪画面，成片保留参考片的章节结构、黑金配色和持续变化的画面节奏。

先阅读 [画面与动效规范](references/style.md)。参考片的具体观察与测量保存在原项目的 `ANALYSIS.md`；制作新题材时不要沿用参考片的 DeepSeek 事实、截图或论点。

## 输入与策划

1. 读取用户文案和提供的图片、视频、录音、来源链接。没有文案时，围绕主题写可核查的解说稿；明确事实、分析和推测。涉及新闻、价格、公司、法规等会变化的信息，先核实日期与原始来源。
2. 把文案分成一个悬念开头、约三个递进章节和一个回扣结尾。每句旁白拆成镜头表：时码、口播、主视觉、证据出处、字幕和动效。章节数量按内容调整，不强套参考片。
3. 为每一条可验证的关键断言准备可读的证据：原文截图、报道标题、官方数据或标明出处的图表。新闻截图只呈现其实际报道内容；不要画出虚假的媒体页面。对来源不充分的数字加“据报道”“估算”等限定。

## 制作

1. 竖屏 9:16，黑色轻纹理画布，金色章节标记和强调色，白色粗体主字幕。前段用实拍或新闻素材快速建立情境；进入正文后在资料卡、时间线、关系图、对比表、大数字和少量实拍之间切换。
2. 每一小段至少有一种信息变化：字幕更新、证据聚焦、数字增长、时间线点亮、关系线连入、卡片展开或镜头推进。大版式维持可读时间，不用无意义的连续转场凑密度。
3. 旁白为主，低音量氛围音乐和少量轻音效托住信息节奏。除非用户明确要求静音，交付前要确认人声和 AAC 音轨实际存在。
4. 在画面底部保留一句式字幕，关键资料旁标来源、发布日期或抓取日期。来源字可小但须在手机上能辨认；不要被平台 UI 或裁切遮住。

## 验收与交付

- 用同一镜头表核对旁白、字幕、证据和画面时码；抽查开头、每章转场、数据页和结尾。
- 导出 H.264 MP4 + AAC，核对 9:16 分辨率、帧率、时长、音轨，并完整解码一次。检查字体回退、错字、溢出、来源可读性和音乐盖人声。
- 用户给成片任务时，交付可播放视频以及镜头表/来源清单；用户只要拆解时，交付分析与这个可复用 Skill，不把拆解误报为已经生成新视频。
